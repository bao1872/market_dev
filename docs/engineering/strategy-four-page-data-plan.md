## 一份批次，四个页面

| 页面 | 必须产出的数据 | 验收 |
|---|---|---|
| 个股 | 权威前复权日线；TV末段含虚/实线及方向；每个决策日五类14任务的适用分数/阈值、锚点日期、阶段、失效状态；首次突破；个股任务/趋势评价及联合路径评价 | ≥90真实bar（默认180）；单副图与主图严格同时间；无任务不补零；个股统计能回溯到明细 |
| 历史评价 | D0、L1、L2按任务/高低点/阶段的样本与Precision、Recall、AUC；按当时TV末段上下方向的端点确认评价；联合报警及D1-D3首次突破的收益/不利路径分布 | TEST与POST_TEST独立；结构标签成熟和20-bar路径成熟分别计数；包含未成熟/不适用/排除原因；无双类时AUC为空并说明 |
| 今日机会 | 最新有效交易日全市场适用候选；保留L1/L2，同时增量展示D1-D3首次突破；按TV最后一段上升/下降分组；末段收益、bar数和约定斜率 | 方向用当日可见TV末段；L2条件概率不标成交易胜率；有效零候选与未计算/失败分开；列表可定位个股精确评分点 |
| 模型与运行管理 | 已安装/已接收/验证中/待激活/现役身份；lab真实训练报告与切割；计算范围、进度、覆盖、排除、耗时、错误、最近成功批次和盘后状态 | 无现役模型也展示已安装14模型和具体阻碍；各步骤可见；不再提供训练入口；仅现役用于日常任务 |

四页统一消费 model SHA、batch ID、source SHA、as_of、evaluation protocol；不各自扫描全市场重算。
行情读取不应被模型快照不可用阻断；未选择个股时明确提示选择，不把它表现为空白。

## 执行顺序

1. **完成现有模型交付核查，不重训**：沿用已训练14权重及原始身份，核实实际训练切割和全部研究报告。
   明确原训练价格口径；以生产MDAS前复权输入做独立lab黄金样例和现有模型的迁移评价。
   原未复权训练/测试成绩保留来源标记；不得改写成前复权成绩。若研究权重不能获得如实交付，
   保留真实阻塞，不伪造 QFQ 或 approved 声明。
2. **补齐首次初始化与验收读取**：复用 lab_delivery → EVALUATE → partitioned_build。
   管理页先展示安装包、交付证据及阻断项；管理员能够只读预览指定已验证候选批次，
   明确“待激活”，不切 active/current，不向普通用户混入候选版本。
3. **少量真实样本验证后执行全市场初始化**：先覆盖上下趋势、D0、各D1-D3、L2、首次突破、
   无候选和缺数据等真实样例，检查实际CPU/RSS/耗时与因果一致性，再用同一owner执行全市场。
   小样例结果只作诊断，不能发布成全市场完成。不能沿用旧训练耗时估算。
4. **初始化计算范围**：as_of先固定2026-10-16；历史评价覆盖实际lab TEST完整区间，
   测试结束后到as_of单列POST_TEST；覆盖所需行情预热历史，不能用图表180bar截断特征历史。
   不沿用已终止训练的24/6/3切割替代现有lab包实际切割。
   每日以当日可见前缀生成评分/TV结构，评价标签最多用as_of可见后续；绝不回填未来评分。
5. **一次构建所有视图资产**：逐股持久化评分/图表/评价明细，再归集全市场每日候选与统计；
   无信号证券也纳入覆盖表。路径成熟自动更新；结构成熟独立更新，超过20bar仍不截断。
   复用前缀缓存和逐股checkpoint；基准确认前不另造流式ZigZag或改变冻结算法。
6. **四页验收后等待人工激活**：对账分母、逐任务与逐股聚合、版本、覆盖、日期、路径与
   结构状态；给出候选批次/报告摘要。人工激活后才验证公共API与四页的现役数据闭环。
7. **日常盘后**：在现有交易日/数据ready owner之后，复用现役模型计算新增日期并更新未成熟评价，
   产出完整新批次后原子切换当日结果。失败保留上个成功批次并标明陈旧日期；有界重试、
   漏跑补偿及指定日期重跑沿用现有队列，不能重复入队或把心跳当作完成。

## 必须补的实现与证据

- 管理页安装包清单和阶段状态；管理员候选批次读取的权限隔离与身份合同。
- 明确初始化区间与日常区间，证明TEST统计不被图表保留范围静默截断。
- 检查全市场归集是否分页/按需汇总，避免每次切筛选重新加载全部逐股历史。
- 复核重复 replay/features 的成本；只有同输入逐值对账通过才启用减少重复计算的优化。
- 修改范围纯测试、跨页同批次/访问权限/幂等恢复合同测试；需要PG的权限/持久化证据走登记验证计划。
- 真实样例→全市场批次→管理员预览→人工激活→公共API→四页浏览器验证分别记录，不混成一个成功状态。

## 完成定义

不是“每个页面有数字”：是数据覆盖与排除可解释、每页身份一致、明细可追溯、历史无未来泄漏，
没有候选/未成熟/未计算/失败可区分，盘后能够持续生成新结果。
模型管理应立即有真实状态；另外三页必须有真实计算批次才能展示模型结果，禁止用占位数据填充。
