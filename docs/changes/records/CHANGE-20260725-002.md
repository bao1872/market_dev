# CHANGE-20260725-002：个股详情左侧来源列表切股闪烁修复

## 变更编号
CHANGE-20260725-002

## 任务名称
个股详情左侧来源列表切股闪烁修复（Persistent Source Context）

## 需求出处
用户报告：切换到未缓存 symbol 时，左侧来源列表消失再出现（闪烁）；缓存命中时不闪。

## 修改前行为
1. `StockDetailPage` 顶层有两个页面级 early return：
   - `if (researchData.instrumentQuery.isLoading) { return <loading 占位> }`
   - `if (!researchData.instrumentQuery.data) { return <未找到占位> }`
2. 切换到未缓存 symbol 时，`instrumentQuery.isLoading` 变 true，整个页面早退到 loading 占位
3. `tv-detail-layout` 和 `tv-source-list`（左侧来源列表）被卸载
4. 数据返回后重新挂载 → 闪烁（DOM 重建、scrollTop 丢失、React Query 重新请求）
5. 缓存命中时 `isLoading` 为 false，不触发早退，故不闪

## 修改后行为
1. 删除两个页面级 early return（`isLoading` 和 `!data`）
2. `tv-detail-layout` 和 `tv-source-list` 始终挂载（不依赖 instrumentQuery 状态）
3. 顶部信息栏条件化渲染：
   - `inst` 存在：显示股票名称/symbol/sourceBadge/metaParts
   - `instrumentLoading`：显示"加载中..."+ URL symbol
   - 其他：显示"未找到股票"+ URL symbol
4. 右侧详情（StockResearchWorkspace）通过 researchData 自然处理 loading（barsQuery.isLoading）
5. 来源列表渲染条件不变（仅依赖 detailActions.sourceListLoading/Error/Empty/ContextInvalid）
6. 来源列表 aside 容器无 `key={symbol}`（保持同一 DOM 节点，scrollTop 不丢）
7. 备忘录按钮添加 `disabled={!instrumentId}`（防止 inst 未就绪时打开 modal 崩溃）
8. metaParts 条件化构造（inst 存在时才访问 inst.market）
