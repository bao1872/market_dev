# 复盘模块 PRD

状态：草案  
最后确认日期：2026-07-26  
对应 Map：`../maps/70-review.md`  
需求所有权：复盘模块目标、边界和预留能力

## 1. 当前状态

复盘管理已经作为独立权限存在，但具体产品功能仍待开发。

## 2. 已确认需求

### RV-01 独立权限

复盘能力由“复盘管理”权限独立控制。

### RV-02 不提前推断

在功能需求确认前，不得根据“复盘”名称自行建设完整交易日志、收益统计、社交分享或策略回测系统。

### RV-03 数据复用

未来复盘应优先复用盘后正式结果、个股状态、事件和市场分布，不重复计算另一套事实。

### RV-04 设计目标

复盘模块应帮助用户理解：

- 当时市场状态；
- 个股状态；
- 事件变化；
- 用户当时的判断；
- 后续变化。

### RV-05 当前允许预留

允许保留明确、低成本且不改变现有行为的权限入口或路由占位，但不得伪装成已完成功能。

## 3. 当前非目标

在进一步确认前，不建设：

- 自动交易归因；
- 完整券商对账；
- 收益排行榜；
- 社交社区；
- 自动生成买卖建议；
- 无需求依据的复杂复盘模板。

## 4. 验收标准

- 未拥有复盘权限的用户不能访问未来复盘功能。
- 当前占位状态明确，不向用户显示虚假完成能力。
- Map 如实记录当前只有权限、路由或占位的实际范围。
