## 1. 摘要

F1 PRD Alignment 最后一次 docs-only correction。本轮**不是重新设计 Auction**，而是修复三类已确认的基础合同一致性问题：

1. **auction_volume canonical fact consistency**：Auction canonical dimension 统一为 Gap + Volume + Amount，`auction_volume` 正式进入 Stock Auction Fact（AU-04）。
2. **metric-specific eligibility / denominator**：废除单一 global valid member count 作为全部 Scope metric 的统一分母，改为每个 metric 根据自身事实与历史 readiness 定义独立 eligible member set（AU-18 重写 + AU-11 / AU-12 / AU-22 同步）。
3. **future phase sequence correction**：CHANGE-20260815-007 §12 后续流程从「Code Alignment → kernel extraction → Historical Validation」修正为「F2 Architecture → F3 Data Contract + Historical Validation → F4/F5 Implementation → Runtime/Acceptance」，移除提前冻结的 statistics_kernel / aggregation_kernel / historical_position_kernel 名称。

本轮为 docs-only：未改代码、未建表、未 migration、未改 API/前端/Maps/Runbooks/治理、未冻结任何阈值、未决定任何 kernel、未决定任何 provider。

## 2. 背景与问题

- CHANGE-20260815-007 已完成 Auction 完整分析合同收口，但仍残留三类基础矛盾，阻塞 F1 PRD Alignment 正式 CLOSED：
- **A. Volume Contract Inconsistency**：PRD 顶层已声明正式输入为 Gap + Volume + Amount，但 AU-04 Stock Auction Fact 只正式定义 price / previous_close / gap_pct / auction_amount；上层已使用 volume_multiple / volume_percentile / total auction volume / volume abnormal breadth / auction_volume member attribution，底层 fact 却缺 auction_volume。属 Specification Defect。
- **B. Denominator Contract Defect**：AU-18 定义单一 valid member（当前 quote valid + 最低历史样本），AU-11 把全部 breadth 分母都写成 valid member count，会错误排除「今天数据有效、但历史样本不足」的股票（例如应参与 positive gap breadth，但不能参与 gap historical abnormal breadth）。
- **C. CHANGE Workflow Drift**：CHANGE-20260815-007 §12 写成 Code Alignment → kernel extraction → Historical Validation，与已确认流程 Architecture → Historical Validation → Implementation 冲突，且提前冻结了 statistics_kernel / aggregation_kernel / historical_position_kernel。

## 4. 变化内容

产品/业务合同修正（全部在 `75-auction-analysis.md`）：

- §0.1 / §1.1：底层事实与产品目标显式列出 Gap + Volume + Amount 三维。
- AU-04：Stock Auction Fact 重构为 PRICE（auction_price / previous_close / gap_pct）+ PARTICIPATION（auction_volume / auction_amount）；新增 AU-04-3 冻结边界（只冻结 auction_volume 是 canonical member fact；provider unit / normalization / lot-share 换算留 Data Contract / Architecture）。
- AU-11：移除「分母均为 valid member count」全局表述；13 项逐类标注 denominator 为 current Gap eligible / Gap-history eligible / current Volume eligible / Volume-history eligible / current Amount eligible / Amount-history eligible / joint eligible（= Gap-history ∩ Amount-history）；新增 AU-11-1 说明这是 eligibility contract 非 schema 字段名。
- AU-12：AuctionAmountContribution 用 current Amount eligible members；normalized HHI 的 N 改为「用于该 Scope amount-share distribution 的 eligible members 数量」（不再笼统 global valid member count）。
- AU-18：标题改为「数据质量 / Metric Eligibility / Denominator」；新增 AU-18-1 各 metric-specific eligibility 合同表（current Gap / Gap-history / current Volume / Volume-history / current Amount / Amount-history / joint）；AU-18-2 Concentration eligible members；AU-18-3 排除规则（missing ≠ zero，invalid ≠ zero，historical-not-ready ≠ current-invalid，不得因历史不足删除今天有效股票）；AU-18-4 numerator/denominator/eligibility 可追溯要求；核心原则：不再使用 global valid member count 作统一分母。
- AU-21 P0 INCLUDE：新增 Auction volume / Volume historical abnormality / Volume abnormal breadth 条目，Auction raw fact 显式列全五个字段。
- AU-22 Acceptance Matrix：Scope Breadth 行改为「各指标按 metric-specific eligibility 定义 denominator（非 global valid member count）」；Amount Contribution / Concentration 行注明 normalized HHI 的 N = amount-share distribution eligible members；数据质量行改为「各 metric 按 metric-specific eligibility 定义 denominator」。
