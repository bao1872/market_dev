# 行情与参考数据 PRD

状态：草案  
最后确认日期：2026-07-26  
对应 Map：`../maps/10-market-data.md`  
需求所有权：行情、参考数据、数据来源、数据口径和 readiness

## 1. 目标

为盘迹的计算、展示、筛选、监控和复盘提供一致、可追踪的数据基础。

## 2. 已确认需求

### MD-01 数据范围

至少支持：

- 股票基础信息；
- A 股日线行情；
- 必要的分钟行情；
- 成交量和成交额；
- 复权数据；
- 交易日历；
- 行业和概念；
- 股票与行业、概念的映射；
- 盘后计算所需参考数据；
- 经管理员明确上传的数据。

### MD-02 日线优先

盘后主计算以日线为优先。分钟数据仅在对应功能或指标明确需要时使用。

### MD-03 统一业务时区

交易日、行情日期和任务日期使用 `Asia/Shanghai` 语义。

### MD-04 统一股票标识

股票代码、交易所和内部标识必须采用统一口径，不得由不同模块自行转换。

### MD-05 复权口径明确

所有依赖历史价格连续性的计算必须明确复权方式。不同计算不能因调用路径不同而改变复权口径。

### MD-06 数据来源可识别

每类数据应有明确来源。发生 fallback、手工上传或回填时，结果必须能够识别实际来源。

### MD-07 缺失语义明确

系统必须区分：

- 正常无交易；
- 停牌；
- 尚未更新；
- 数据源失败；
- 数据缺失；
- 历史长度不足；
- 手工补录。

不得用零值或空对象掩盖缺失。

### MD-08 Readiness

数据进入正式下游计算前，应能够判断：

- 是否为交易日；
- 目标日期是否完整；
- 必要股票是否覆盖；
- 必要周期是否齐全；
- 复权处理是否完成；
- 必要参考关系是否可用；
- 是否发生数据源失败或降级。

### MD-09 数据分层

逻辑上区分：

- 原始或外部数据；
- 标准化数据；
- 复权或转换数据；
- 因子与事件等派生结果；
- 临时运行状态。

### MD-10 核心资产与可重算结果分离

长期行情及参考数据属于核心资产。因子、特征、事件和中间结果属于可重算数据，两者采用不同保护策略。

### MD-11 数据修复范围明确

修复、回填和覆盖必须明确日期、股票、来源、影响范围和下游重算要求。

## 3. 验收标准

- 相同股票和日期在不同模块中数据口径一致。
- readiness 能明确返回 ready 或 not ready 及原因。
- 数据来源、缺失和降级状态可识别。
- 核心数据不会因普通开发任务被无范围删除。
- Map 能为 MD-01 至 MD-11 指向实际数据入口、存储和验证证据。

## 4. 未决问题

- 各类数据最终主来源和备用来源；
- readiness 覆盖阈值；
- 行业分类最终权威口径；
- 管理员 CSV 的正式适用范围。
