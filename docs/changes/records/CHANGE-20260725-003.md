## 任务名称

## 需求出处

## 修改前行为
1. 权限模型：单一 `subscription.status=active` + `plan.monitor_limit`；所有写操作只检查 `require_active_subscription`；自选额度从 `plan.monitor_limit` 读取
2. 邀请码：V1 `/admin/invite-codes` + `/auth/redeem`，绑定 plan_code/grant_months，无能力配置
3. 前端路由守卫：`SubscriberRoute`（admin 直通 + subscription_active）；`/market`、`/stock/:symbol` 守卫相同
4. 监控资格：`is_user_eligible_for_monitor` 直接读 subscription
5. 自选并发：无行锁，理论上存在 race condition（虽然 `monitor_limit` 检查 + INSERT 之间窗口小）
6. token 撤销：仅 `users.status` 状态机，无 token_version/jti 黑名单
