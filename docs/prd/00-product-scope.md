# 产品范围与定位

状态：已确认  
最后确认日期：2026-07-26  
对应 Map：`../maps/00-system-overview.md`  
需求所有权：产品定位、目标用户、模块边界和核心术语

## 1. 目标

盘迹通过组合行情、价格结构、因子、事件和板块分布，帮助用户更快理解市场与个股当前状态。

## 2. 已确认需求

### PS-01 产品价值

盘迹的核心价值是减少用户手工组合信息的时间，形成一致、可解释、可复盘的市场和个股状态描述。

### PS-02 产品定位

盘迹是 A 股市场结构与状态分析工具，重点服务于：

- 盘后选股；
- 市场全貌理解；
- 个股结构拆解；
- 自选管理；
- 盘中异常信息；
- 后续复盘。

### PS-03 非预测定位

盘迹不以预测涨跌、承诺收益或替用户作交易决策为定位。

### PS-04 目标用户

当前主要用户是有 A 股交易经验、愿意自行决策、希望降低信息整合成本的投资者和内部测试成员。

### PS-05 核心模块

当前模块包括：

1. 行情列表；
2. 个股详情；
3. 自选管理；
4. 盘中监控；
5. 盘后计算与发布；
6. 权限和邀请码；
7. 管理后台；
8. 复盘模块。

### PS-06 产品表达

系统应优先呈现：

```text
事实 → 状态 → 变化 → 异常 → 市场分布 → 用户判断
```

不得把模型状态包装成确定性预测。静态 State 不得默认等价于用户可见 Discovery。

### PS-07 当前非目标

当前不默认建设：

- 自动下单；
- 高频交易执行；
- 收益保证；
- 喊单社区；
- 无明确需求的通用因子市场；
- 多市场统一交易平台。

## 3. 核心术语

### 趋势

由长周期价格与成交量关系描述的持续方向，当前主要由 DSA VWAP 体系承担。

### 结构

价格在中周期内形成的高低点、BOS、CHoCH、OB 等关系，当前主要由 SMC 体系承担。

### 动量

价格和成交量在较短周期内的收缩、扩张、扩散和变化速度，当前主要由 Bollinger 相关体系承担。

### 筹码共识

由 Node Cluster、价值共识区等方法描述的短期或很短期筹码集中和关键价格区域。

### 事件

某个明确条件在特定时间发生，例如 BOS、CHoCH、进入 OB、连续高点、连续低点和筹码峰穿越。

### 正式结果

经过完整计算、校验并满足发布条件后，被系统认定为当前可供正式读取的结果。

## 4. 验收标准

- PS-01 至 PS-07 在门户、行情、个股、权限和盘后产品行为中不存在明显冲突。
- 用户可见文案不得出现收益保证和确定性预测表达。
- 各领域 PRD 使用本文件术语时保持一致。
