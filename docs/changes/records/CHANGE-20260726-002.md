## 为什么 AGENTS 变为入口和路由器

- AGENTS.md 单文件 46 条规则按主题检索困难；
- rules/ 按主题拆分后便于检索与维护；
- AGENTS.md 保留入口、路由器、最高安全边界，详细规则指向 rules/；
- 两层结构清晰：AGENTS.md 回答"做什么前先读什么、哪些事绝对不能做"，rules/ 回答"具体规则是什么"。

## 为什么修正 TRAE Work 的真实自动分支机制

- 旧 AGENTS.md §九 仅描述传统独立分支模型，未反映 TRAE Work 的真实机制；
- TRAE Work 实际使用系统生成的 trae/agent-* 内部分支，不能切换；
- 完成后使用 git push origin HEAD:dev 以 fast-forward 方式推送；
- 必须在开始任务时确认 origin/dev 是当前 HEAD 祖先，否则停止；
- 禁止 force push。

## 为什么 sync 是临时中转站

- sync/ 用于跨会话传递任务材料与草案；
- 不是正式真源，不得作为运行时依赖；
- 默认报告直接在对话中输出完整纯文本；
- 中转材料完成迁移后应清理或归档。
