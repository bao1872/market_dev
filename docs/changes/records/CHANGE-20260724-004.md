# CHANGE-20260724-004：个股详情布局与行情唯一真源修复

## 变更编号
CHANGE-20260724-004

## 任务名称
个股详情布局与行情唯一真源修复（stock-detail-market-data-v1）

## 需求出处
`ref/PROMPT.md` — 个股详情布局与行情唯一真源修复任务

## 修改前行为
1. 详情页同时调用 `/chart-snapshot` 和 `/quote`，两个数据源 `as_of` 不一致
2. 15m/1h 实时尾部从 1m 聚合（`_aggregate_minute_to_target`），非 Pytdx 原生周期
3. 1d partial daily 从 1m 聚合（`_aggregate_minute_to_daily`），非 Pytdx 原生日线
4. 1w/1mo 先聚合再补今日，最后一根 bar 不含今日数据
5. 1w/1mo quote 使用聚合 OHLC，非当日行情
6. 实时空结果返回普通 db 状态，无 stale 标记
7. PytdxAdapter 使用 `Lock`（不可重入），嵌套调用自锁
8. freshness 无明确状态机，使用泛化"行情回退"文案
9. 详情页布局不区分 direct/market/watchlist 来源
10. MessagesPage 手拼 `/stock/:symbol`

## 修改后行为
1. 详情页唯一行情真源为 `/chart-snapshot`，删除 `useRealtimeQuote`
2. 15m 实时尾部使用 `fetch_15min_bars`（Pytdx 原生 15m）
3. 1h 实时尾部使用 `fetch_60min_bars`（Pytdx 原生 60m）
4. 1d 实时尾部使用 `fetch_today_daily_bars`（Pytdx 原生日线）
5. 1w/1mo 先合并今日 partial daily 再聚合周/月线
6. **[P0 修正] quote 与展示周期完全解耦**：`BarAggregationResult.latest_daily_quote` 字段在单次 MDAS 读取内派生当日行情事实
   - 1d/1w/1mo：从聚合前 `daily_df`（已合并今日 partial + qfq）取末根日线 OHLC
   - 1m/15m/1h：从已加载目标周期 `bars_df_full`（limit 截断前）按最新交易日聚合 open/high/low/close/volume/amount
   - **禁止为 quote 增加第二次 Pytdx/Repository/MDAS 行情读取**
   - 所有周期返回 `current/open/high/low/prev_close/change_pct/volume/amount`，业务语义不随展示周期变化
   - `latest_daily_quote` 缺失时 `quote=null` 且 `freshness_state=unavailable`；禁止从 1w/1mo page_df 派生日行情兜底
7. 实时空结果标记 `degraded=True` + `realtime_{tf}_empty_in_trading_hours` reason
8. PytdxAdapter 使用 `RLock`（可重入），防止嵌套自锁
9. freshness_state 状态机：fresh/partial/stale/unavailable，对应文案：实时行情/当期未完成/数据延迟/行情不可用
10. 布局：direct 单列，market/watchlist 双列；统一使用 `buildStockDetailUrl`
11. **[Live Mount] `/version` 端点**：优先读取 `/app/RUNTIME_SHA`，返回 `runtime_git_sha`/`image_git_sha`/`deployment_mode`；兼容旧镜像环境变量
12. **[Live Mount] docker-compose.live.yml**：叠加 prod 配置的只读 bind mount；backend + 所有 Python worker + capture worker 挂载 app/alembic/alembic.ini/RUNTIME_SHA；frontend 挂载 dist
13. **[Live Mount] sync/deploy 脚本**：`scripts/sync_live_runtime.sh`（rsync --delete 同步运行必需文件）；`scripts/deploy_live_runtime.sh`（完整部署编排）
