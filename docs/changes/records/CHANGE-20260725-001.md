# CHANGE-20260725-001：freshness_state 日级周期日期比较修正

## 变更编号
CHANGE-20260725-001

## 任务名称
freshness_state 日级周期（1d/1w/1mo）actual vs expected 日期比较修正

## 需求出处
`ref/PROMPT.md` P0 第 6/7 项 — `expected_latest_bar_time` 按周期计算、`freshness_state` 真实比较 actual/expected

## 修改前行为
1. 日级周期（1d/1w/1mo）bar 在 DB 中以当日 `00:00:00` 时间戳存储
2. `expected_latest_bar_time` 按 `15:00`（收盘）计算
3. `_compute_freshness_state` 对所有周期统一用 `actual < expected` 精确时间比较
4. 导致非交易日（如周六）已有上一交易日完整日线 bar 时，`actual=00:00 < expected=15:00` → `freshness_state=unavailable`
5. 违反合同"实时目标缺失才 stale/unavailable"——数据并未缺失

## 修改后行为
1. `_compute_freshness_state` 新增 `timeframe` 参数
2. 日级周期（1d/1w/1mo）按 **日期** 比较：`actual.date() < expected.date()` 才判为过期
3. 日内周期（15m/1h）保持精确时间比较
4. 非交易日已有上一交易日日线 bar → `freshness_state=fresh`（正确）
5. 交易时段日级 bar 缺失当日 → `stale`/`unavailable`（正确）

## 修改文件
- `backend/app/api/chart_snapshot.py`：
  - `_compute_freshness_state` 新增 `timeframe: str` 参数
  - 日级周期按 `actual.date() < expected.date()` 比较
  - 调用点传入 `timeframe=timeframe`
- `backend/tests/test_stock_detail_market_data_contract.py`：
  - `test_16_weekly_quote_unavailable_no_fallback` 传入 `timeframe="1w"`
