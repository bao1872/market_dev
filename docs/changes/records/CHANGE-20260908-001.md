## 1. 摘要

公开根路径 `/` 从 Help Center（`/portal/index.html`）拆分为独立产品官网（`/landing/index.html`）。
Help Center 继续保留在 `/portal/`，二者职责分离：官网负责「为什么需要盘迹」，帮助中心负责「怎么用」。
官网不出现任何价格信息与内部术语。

## 2. 背景与问题

- 变化前：`/` 精确匹配直接返回 `/portal/index.html`（2026-07-23 导入的静态门户）。
- 问题：产品官网与使用说明混在同一入口，且开发环境 `LandingPage` 也跳到门户，无法传达「盘迹是什么」。
- 触发：用户 redesign 合同（PANJI PUBLIC SITE V2）。

## 3. 变化前

- nginx `location = /` → `try_files /portal/index.html =404`。
- `LandingPage.tsx` 开发环境 `window.location.replace('/portal/index.html')`。
- Help Center `site.css` 使用旧绿 `--accent:#50e37d`。

## 4. 变化内容

- 新增 `frontend/public/landing/`（index.html + assets/css/landing.css + assets/images/）。
- nginx：`location = /` 改为 `try_files /landing/index.html =404`；新增 `location = /landing/index.html`
  与 `location /landing/assets/`（静态资源可缓存）。
- `LandingPage.tsx` 开发环境跳转目标改为 `/landing/index.html`，兜底视觉对齐 PANJI 调色板。
- Help Center `site.css` `:root` token 统一为盘迹品牌调色板（绿 → 青），未重构 DOM。
- 批准 Logo 复制至 `frontend/public/landing/assets/images/logo_symbol_128.png`（不改色/不重绘）。
- 新增 `scripts/prepare_landing_assets.py`：将用户提供原图导出 WebP，并对盘中监控截图二维码做马赛克匿名化。

## 5. 变化后

- `/` 返回产品官网；`/portal/` 仍返回 Help Center；`/login`、`/market`、`/api/*`、`/umami/*`、
  `/capture/*`、SPA fallback 全部不变。
- 官网传达五类能力（全市场筛选 / 盘中监控 / 筹码共识 / 自选持续观察 / 飞书即时推送），无价格信息。
