# CHANGE-20260724-002

## 变更编号
CHANGE-20260724-002

## 任务名称
盘迹统一特征计算与事件新鲜度 V1 — 状态机收敛 + compute-once + event freshness 层 + v5 schema

## 需求出处
- 资料包 `ref/盘迹_统一特征计算与事件新鲜度_开发资料包_V1/`（01_PRD / 02_开发计划 / 03_测试计划 / 06_执行指令）
- 目标：盘后 `creating_dsa/waiting_dsa_worker/quality_gate/feature_snapshot` 收敛为 `computing_features`；每股 DSA/SMC 只算一次；新增 event_freshness_payload；schema v4→v5

## 修改前行为
- 盘后状态机：`queued → refreshing_daily → syncing_boards → checking_coverage → creating_dsa → waiting_dsa_worker → quality_gate → feature_snapshot → publishing → succeeded`
- `_SCHEMA_VERSION = 4`；snapshot 无 `event_freshness_payload` 列
- SMC freshness（14 项）存储在 `structural_payload.smc_freshness`，由 `_compute_smc_freshness_factors` 内部调 `compute_smc_adapter` 计算
- `_compute_all_factors_for_bars` 每次调 `compute_dsa_bundle(bars, {})`，无 precomputed 注入
- `detect_crossover_signals` 只输出 `dev_pct`，无 `cross_direction`
- DSA 门禁在 orchestrator 执行一次，snapshot 失败率门禁在 feature_snapshot_service 内
- 无批量事件聚合；无 event freshness 层

## 修改后行为
- 盘后状态机：`queued → refreshing_daily → syncing_boards → checking_coverage → computing_features → publishing → succeeded`
  - `computing_features` 内部 checkpoint：`prepare_inputs → continuous_factors → event_freshness → combined_quality_gate`
- `_SCHEMA_VERSION = 5`；新增 `stock_feature_snapshots.event_freshness_payload JSONB NOT NULL DEFAULT '{}'`
- SMC freshness 迁出到 `event_freshness_payload.daily_structure.smc`，`structural_payload` 不再含 `smc_freshness`
- 新增 swing anchor（6 类）、OB formation（4 项）、DSA switch（1 项）
- `compute_structural_features_adapter` 支持 `precomputed_dsa_bundle`；盘后日线 DSA 只算一次，同时写 StrategyResult 和 snapshot dsa_segment
- `_compute_smc_freshness_factors` 接收 `precomputed_smc_dto`，不再内部调 `compute_smc_adapter`
- `detect_crossover_signals` 显式输出 `cross_direction=up|down` + `node_id/node_price/strength/is_poc/profile_hash`
- Bollinger payload 显式 `cross_direction`
- 批量查询 `strategy_events`（DISTINCT ON / 窗口函数），禁止 N+1
- 组合门禁（DSA + continuous + event）在 `computing_features` 末尾执行一次
- 保留 heartbeat、lease_epoch、attempt_no、幂等和恢复
