# 60 TRAE Work

## 定位

主要云端开发环境。

## 可以

- 在 dev 做小型增量；
- 在临时分支做复杂任务；
- 运行前端预览；
- 运行代码测试；
- push dev 触发自动部署；
- 生成 migration 但不执行真实 migration。

## 不可以

- SSH 腾讯云；
- 获取真实数据库；
- 操作真实 Docker；
- 执行真实飞书；
- 断言腾讯云部署成功。

## 交接

当任务需要真实验证时，输出：

- Target SHA；
- 自动部署预期；
- 受影响服务；
- migration；
- 验收路径；
- 日志入口；
- 回滚点。
