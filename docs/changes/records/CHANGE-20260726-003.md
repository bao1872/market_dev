## 变更编号

CHANGE-20260726-003

## 任务名称

建立统一 reports 报告管理体系

## 需求出处

用户指令：实施盘迹项目统一 Reports 报告管理体系，替代此前"所有完整报告都直接输出到对话"的约定。完整任务报告必须写入 `reports/`，对话只输出简短摘要 + 路径 + commit + push。

## 修改前行为

1. 完整任务报告直接在 TRAE 对话中输出（几百行）；
2. 历史报告保存在 `sync/outbox/`（`project-governance-audit.md`、`project-governance-phase1.md`）；
3. 无统一报告模板；
4. 无 `reports/` 目录；
5. 无 `LATEST.md` / `INDEX.md` 入口；
6. 无 reports 检查器；
7. AGENTS / rules / sync / AI-ONBOARDING 未引用 `reports/`。

## 修改后行为

1. 建立 `reports/` 长期报告管理体系：
   - `reports/README.md`（10 节管理规则）；
   - `reports/INDEX.md`（按日期倒序的报告索引）；
   - `reports/LATEST.md`（AI 读取最新任务状态的固定入口）；
   - `reports/templates/TASK-REPORT-TEMPLATE.md`（固定 15 章节统一模板）；
   - `reports/current/`（正在进行或刚完成的报告）；
   - `reports/archive/YYYY/MM/`（历史报告归档）；
2. 完整任务报告统一写入 `reports/current/REPORT-YYYYMMDD-NNN-任务短名称.md`，使用统一模板；
3. TRAE 对话只输出简短摘要 + 报告路径 + commit SHA + push 结果 + blocker；
4. 不再创建 `sync/outbox/*.md`；
5. 历史报告迁移到 `reports/archive/2026/07/`：
   - `REPORT-20260726-001-governance-audit.md`（原 `sync/outbox/project-governance-audit.md`，git mv 保留历史，添加 Legacy Report Metadata）；
   - `REPORT-20260726-002-governance-phase1.md`（原 `sync/outbox/project-governance-phase1.md`，git mv 保留历史，添加 Legacy Report Metadata）；
6. `sync/outbox/` 已删除；
7. `sync/README.md` 删除"使用 outbox 保存长期报告"描述，新增 reports 迁移说明；
8. `reports/LATEST.md` 是 AI 读取最新任务状态的固定入口；
9. 新增 `tools/check_reports.py`（15 项检查，覆盖用户要求的 18 项检查点）；
10. CI 新增 `reports` 检查 job（`.github/workflows/ci.yml`）；
11. `AGENTS.md` 必读顺序纳入 `reports/LATEST.md`，最高风险禁止项加入 `check_reports.py`，质量门禁加入 `Reports`，完成报告格式引用 `reports/`；
12. `rules/40-testing-quality.md` 新增 Reports 报告体系主归属规则（12 条要点）；
13. `rules/60-trae-work.md` 新增 reports 输出规则；
14. `rules/70-trae-cn.md` 新增 reports 输出规则；
15. `docs/AI-ONBOARDING.md` 读取顺序纳入 `reports/LATEST.md`；
16. 创建本轮实施报告 `reports/current/REPORT-20260726-003-reports-governance.md`。
